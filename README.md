# Credit-Card-Fraud-Analysis
This dataset contains 555,719 credit card transactions made between 21 June 2020 and 31 December 2020, along with customer, merchant, and location details. Each transaction is labeled as fraudulent or legitimate, which makes it suitable for fraud analysis and dashboarding
i used Python to check data clean or not i used pandas library and also there is short state name which i converted into full name of state by using of pandas mapping
I used Excel for renaming columns name
I used Power Bi (DAX,Data Modeling,Visualisation)
